# 🌐 Proyecto Web – HTML y CSS

Sitio web de varias páginas desarrollado únicamente con **HTML5** y **CSS3**, sin frameworks ni JavaScript. Incluye una página de inicio, un cuestionario, una página de resultados y una página de contacto, con diseño **responsive** para adaptarse a distintos tamaños de pantalla.

## 📄 Páginas del sitio

| Página | Descripción |
|---|---|
| `index.html` | Página principal del sitio. |
| `cuestionario.html` | Página con el cuestionario. |
| `resultados.html` | Página donde se muestran los resultados. |
| `contacto.html` | Página de contacto. |

---

## 📂 Estructura del proyecto

```
├── assets/                  # Recursos del sitio (imágenes, íconos, etc.)
├── index.html               # Página de inicio
├── styles.css               # Estilos de la página de inicio
├── cuestionario.html        # Página del cuestionario
├── cuestionario_styles.css  # Estilos del cuestionario
├── resultados.html          # Página de resultados
├── resultados.css           # Estilos de resultados
├── contacto.html            # Página de contacto
└── contacto_styles.css      # Estilos de contacto
```

Cada página tiene su propia hoja de estilos, lo que mantiene el CSS organizado por sección.

---

## ✨ Características

- Sitio de **múltiples páginas** enlazadas entre sí
- Hojas de estilo **independientes** por página
- Diseño **responsive** (adaptable a móvil, tablet y escritorio)
- Desarrollado solo con **HTML y CSS**, sin dependencias

---

## 🚀 Cómo ejecutarlo

1. Clona el repositorio:
   ```bash
   git clone <URL-DEL-REPOSITORIO>
   ```
2. Entra a la carpeta del proyecto:
   ```bash
   cd <NOMBRE-DEL-REPOSITORIO>
   ```
3. Abre `index.html` en tu navegador (doble clic, o con la extensión **Live Server** de VS Code).

No necesita instalación ni servidor.
